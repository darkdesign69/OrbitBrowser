# Settings status

Every row on every settings page exists and saves. Rows in **Active** already change how Orbit behaves.
Rows in **Saved only** keep your choice but the behaviour behind them is not written yet.

## Active
- Display: UI theme (default Dark), web page dark mode, brightness, screen timeout (always on), screen rotation
- Site: home page, search engine, user agent (Android / Desktop / iPhone), permission, default browser
- Web cleaner: ad blocker, ad filter lists, ad whitelist, overlay blocker + whitelist, popup blocker + whitelist,
  blocked links, blocked images, JavaScript blacklist, disable AMP
- Security / Incognito / Password / Clear data: HTTPS first, SSL error blocking, Safe Browsing, cookies,
  third-party cookies, save history, incognito privacy, app lock, delete on exit, clear now
- Advanced / Web content: JavaScript, desktop site on all tabs, text size, pinch zoom, DOM storage, mixed content
- Tab / Layout / Composition: address bar position, bottom bar, tab bar, tab list style, where to add tabs, restore tabs,
  hide bars while scrolling, full screen, pull to refresh, back to top, volume-key scroll, address bar label,
  scroll bar, back twice to exit
- Menu: popup / bottom-sheet style; Read aloud (+ speed), Translate (+ language)
- Backup: export / import settings, bookmarks HTML / CSV
- TV Cast: opens Android's cast panel. DNS: copies the provider hostname and opens Android Private DNS

## Saved only (no behaviour yet)
Download manager / fast download / retries / concurrency / timeout / notification, Media button colour and YouTube rows,
background playback, Memory saving limits, start page and new tab choice, long-press link / image action,
open link with app, element inspection, block area, block app execution, lock screen, screen filter, header colour,
image brightness, tab swipe gestures / indicator / loop / undelete / last-page behaviour, floating button,
one-handed mode, search suggestions, recent searches, scroll animation, swipe navigation, double tap,
automatic translation, incognito external links, incognito lock.

## Left out on purpose
Purchase page, Google Drive backup, Google sign-in (see FEATURES.md).
